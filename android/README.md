# Отчёт МТС → ВК — приложение для Android

Одно приложение вместо связки «расширение + Tampermonkey + MacroDroid».
Внутри: экран настроек, вход в портал и в ВК (один раз), отправка отчёта
в чат ВК **от вашего имени** — по напоминанию в назначенное время. Всё
работает через встроенный браузер (WebView), никакого бота и токенов.

## Как получить APK

**Проще всего — из готового релиза:**

1. Откройте страницу [**Releases**](../../releases/latest) репозитория.
2. В разделе **Assets** скачайте `otchet-mts-vk.apk`
   (прямая ссылка на последнюю версию:
   <https://github.com/zombo658/topmts/releases/latest>).
3. Перекиньте файл на телефон и откройте его. Разрешите установку из этого
   источника («Неизвестные источники» / «Установка неизвестных приложений»).

Это debug-сборка — она устанавливается напрямую, без Google Play.

**Своя сборка новой версии** (если меняли код): вкладка **Actions** →
**«Сборка Android APK»** → **Run workflow** → укажите версию (например
`v1.1.0`) → по завершении появится новый релиз с APK. Либо возьмите APK из
раздела **Artifacts** любого запуска сборки.

## Первый запуск (один раз)

1. Откройте приложение. Оно попросит разрешить **уведомления** — разрешите.
2. Нажмите **«Войти в портал МТС»** → войдите как обычно. Закройте вход
   кнопкой «назад» — сессия сохранится.
3. Нажмите **«Войти в ВК»** → войдите в свой аккаунт. «Назад».
4. Нажмите **«Выбрать чат из списка»** → откроется ваш список бесед ВК →
   зайдите в нужную беседу, и её номер подставится сам. (Можно и вручную:
   значение `sel=…` из адреса, например `c66`.)
5. Заполните: **домен ВК** (`vk.ru` или `vk.com`), **звонки**, **время**
   напоминания (по умолчанию 22:00), **дни недели**, при желании — **шаблон**.
6. Поставьте галочку **«Напоминать отправить отчёт»** и нажмите
   **«Сохранить настройки»**. Приложение попросит разрешить **«Точные
   будильники»** — разрешите (без этого напоминание может опаздывать).
7. Нажмите **«Собрать и отправить отчёт»** для проверки.

## Как это работает в назначенное время

В назначенное время приходит **уведомление-напоминание**. Одно нажатие по
нему открывает экран отправки: WebView заходит на портал, собирает отчёт
(колонка «Результат оказания услуги», расшифровка, сумма ДМХ, дата, звонки,
пустое = 0) → открывает ваш чат ВК → вставляет текст и жмёт «отправить».
При успехе окно само закрывается; если что-то не вышло — окно остаётся
открытым с уже вставленным отчётом, и его можно отправить вручную.

Почему напоминание, а не полностью автоматическая отправка: Android
запрещает приложениям открывать окна из фона, а без видимого окна WebView
не загружает страницы. Поэтому надёжный путь — уведомление и одно нажатие.

Если сегодня отчёт уже отправлен, напоминание не приходит — защита от дублей.

Чтобы напоминание приходило вовремя, при «Сохранить настройки» приложение
попросит два разрешения — **оба нужно дать**:
1. **Точные будильники** — чтобы срабатывать ровно в назначенное время.
2. **Не экономить батарею для приложения** — иначе система «усыпит» будильник.

## Что важно

- Иногда ВК или портал просят перелогиниться — тогда снова нажмите
  соответствующую кнопку входа.
- На прошивках Xiaomi/MIUI, Huawei, Samsung, Oppo дополнительно включите
  приложению **«Автозапуск»** в настройках системы — иначе напоминание
  может не прийти. Это отдельно от исключения из энергосбережения.
- **Звонки** приложение не знает — задаются вручную в настройках; меняйте
  число перед нужным днём.

## Честные ограничения

- **Только Android.** На iPhone фоновая автоматизация интерфейса запрещена
  системой — там полный автомат возможен только через облако с ботом
  (папка `../automation/`).
- **Самое хрупкое звено — авто-нажатие «отправить»** на мобильном ВК.
  Скрипт пробует кнопку и Enter; если новая вёрстка ВК их заблокирует,
  текст останется вставленным в поле — нужен один тап. Вставка текста
  надёжна. Если так случится — сообщите, подстрою селекторы в
  `ReportJs.kt` (функция `vkBootstrap`).
- Скрытый WebView и энергосбережение — самая частая причина сбоев на
  Android; поэтому важен пункт про автозапуск и батарею выше.

## Исходники

```
android/
  app/src/main/java/ru/topmts/report/
    MainActivity.kt   — экран настроек
    LoginActivity.kt  — вход в портал и ВК (сохранение cookie)
    Settings.kt       — хранение настроек
    ReportJs.kt       — JS сбора данных и отправки в WebView
    ReportRunner.kt   — прогон: портал → сбор → чат → отправка
    RunnerActivity.kt — видимый экран, в котором работает WebView отправки
    ChatPickerActivity.kt — выбор беседы из списка ВК (номер подставляется сам)
    AlarmScheduler.kt — точный будильник по расписанию (напоминание)
    AlarmReceiver.kt / BootReceiver.kt — запуск по времени и после перезагрузки
  app/src/main/res/   — тёмный интерфейс, иконка
```
