# МТС Район — мобильный помощник расклейщика и статистика обхода

Приложение для Android для удобного обхода закреплённого района, ручной отметки пройденных домов и подъездов, расчёта статистики и формирования рабочего отчёта.

## Возможности новой версии 2.0

1. **Список адресов района:**
   * В базу сразу внесены 32 дома вашего района (ул. Рябикова, ул. Камышинская, ул. Самарская, ул. Жигулевская, ул. Корунковой, ул. Кузоватовская, 2-й Брянский пер., ул. Фруктовая, ул. Шолмова).
   * Крупные, чёткие карточки: улица, номер дома, подъезды, квартиры, этажи.
   * Фильтры: «Все», «Осталось пройти», «Пройдено», а также фильтр по конкретной улице района.
   * Мгновенный поиск по улице или номеру дома.

2. **Удобная ручная отметка:**
   * Большая кнопка «Отметить» / «✓ Пройден» прямо на карточке — удобно нажимать на ходу одной рукой.
   * Виброотклик смартфона при нажатии для тактильного подтверждения.
   * Фиксация точного времени прохождения дома (например, `✓ 14:35`).
   * Кнопка детализации подъездов: если поклеены не все подъезды (например, закрыт домофон), можно быстро отметить конкретные подъезды `[1] [2] ...` — карточка покажет `2 из 4 под.` с желтым индикатором.

3. **Добавление и редактирование домов:**
   * Кнопка «+ Добавить дом» внизу экрана: форма добавления (Улица с подсказками, Номер дома, Подъезды, Квартиры, Этажи).
   * Редактирование любого дома или удаление из базы.

4. **Статистика и таймер смены:**
   * Круговой индикатор процента выполнения обхода.
   * Счётчики: сколько домов пройдено / осталось, сколько подъездов поклеено, сколько квартир охвачено.
   * Таймер смены: кнопка Старт / Пауза для отслеживания времени на районе.
   * Автоматический расчёт средней скорости (минут на 1 дом, подъездов в час).
   * Прогресс-бары закрытия по каждой улице отдельно.
   * История предыдущих смен (архив обходов).

5. **Готовый отчёт:**
   * Формирование красивого текстового отчёта со сводкой и перечнем пройденных домов, сгруппированных по улицам.
   * Кнопка «📋 Скопировать в буфер» для быстрой отправки в Telegram/WhatsApp/VK бригадиру или в рабочий чат.
   * Кнопка «🚀 Поделиться» через системное меню Android.

6. **Надёжность и автономность:**
   * Работает полностью офлайн (без интернета во дворах и подъездах).
   * Двойное сохранение данных (в память браузера и во внутреннее хранилище Android через Native Bridge).
   * Возможность экспорта и импорта базы в JSON.

---

## Как получить APK

1. Откройте репозиторий на GitHub.
2. В разделе **Actions** запустится автоматическая сборка **«Сборка Android APK»**.
3. После завершения скачайте готовый `otchet-mts-vk.apk` из вкладки **Releases** или из **Artifacts** сборки.
4. Установите на телефон (разрешите установку из неизвестных источников).
